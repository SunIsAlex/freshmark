常用结论

我们由一个寻常的三元三次对称式出发: a3+b3+c3−3abc=(a+b+c)(a2+b2+c2−ab−bc−ca)=12(a+b+c)[(a−b)2+(b−c)2+(c−a)2]\begin{gathered} a^3+b^3+c^3-3abc\\ =(a+b+c)(a^2+b^2+c^2-ab-bc-ca)\\ =\frac{1}{2}(a+b+c)[(a-b)^2+(b-c)^2+(c-a)^2] \end{gathered}其实还有一个比较神奇的证明方法:

设a,b,ca,b,c为一元三次方程x3−(a+b+c)x2+(ab+bc+ca)x−abc=0x^3-(a+b+c)x^2+(ab+bc+ca)x-abc=0的三个根.

a3+b3+c3=(a+b+c)(a2+b2+c2)−(ab+bc+ca)(a+b+c)+3abc=(a+b+c)(a2+b2+c2−ab−bc−ca)+3abc\begin{gathered} a^3+b^3+c^3\\ =(a+b+c)(a^2+b^2+c^2)-(ab+bc+ca)(a+b+c)+3abc\\ =(a+b+c)(a^2+b^2+c^2-ab-bc-ca)+3abc \end{gathered}

这种证明方法和牛顿恒等式完全一致(挖个坑,以后写).

总之,如果a,b,c∈R,a3+b3+c3−3abc=0a,b,c\in R,a^3+b^3+c^3-3abc=0(※),当且仅当a+b+c=0a+b+c=0或a=b=ca=b=c.

反之,若a+b+c=0a+b+c=0,则a3+b3+c3=3abca^3+b^3+c^3=3abc.

那么我们容易知道,a,b,c∈R+,a3+b3+c3−3abc≥0a,b,c\in R^+,a^3+b^3+c^3-3abc\ge 0

这里挖个坑,以后用叶军老师书中三元三次不等式的通法再次解释.

Δ<0\Delta < 0：三个实根的情形（"不可约情形"）

直觉上的困惑

当 Δ<0\Delta < 0 时，Δ\sqrt{\Delta} 是虚数，于是 v,wv, w 的表达式里出现了复数的立方根——但最终结果却是三个实数。这正是历史上著名的不可约情形(casus irreducibilis)，卡尔达诺本人也对此感到困惑。

用三角方法理解

当 Δ<0\Delta < 0 时，换一种参数化更直观。此时 q+−Δi2\dfrac{q+\sqrt{-\Delta}i}{2} 是一个复数，写成极坐标形式：

q+−Δi2=reiθ\frac{q+\sqrt{-\Delta}i}{2} = r e^{i\theta}q−−Δi2=re−iθ\frac{q-\sqrt{-\Delta}i}{2} = r e^{-i\theta}

其中

r=q2−∣Δ∣4=−p327,θ=arctan⁡−Δqr = \sqrt{\frac{q^2 - |\Delta|}{4}} = \sqrt{-\frac{p^3}{27}}, \quad \theta = \arctan\frac{\sqrt{-\Delta}}{q}

（Δ<0\Delta < 0 时 p<0p < 0，故 rr 是实数。）

uk=−r1/3ei(θ+2kπ)/3+r1/3ei(−θ+2kπ)/3u_k=-r^{1/3} e^{i(\theta + 2k\pi)/3}+r^{1/3} e^{i(-\theta + 2k\pi)/3}，k=0,1,2k=0,1,2，对应三个根：

uk=−2−p3cos⁡(13arccos⁡(3q2p−3p)−2kπ3),k=0,1,2\boxed{u_k = -2\sqrt{-\frac{p}{3}}\cos\left(\frac{1}{3}\arccos\left(\frac{3q}{2p}\sqrt{-\frac{3}{p}}\right) - \frac{2k\pi}{3}\right), \quad k=0,1,2}

三个根全部是实数，因为复数部分在 v+wv+w 相加时恰好相消。

两处更正。

  1. 上面框出的三角公式多了一个负号。它给出的是 u3+pu−q=0u^3+pu-q=0 的根，即真实根的相反数。例如 u3−3u−2=(u−2)(u+1)2u^3-3u-2=(u-2)(u+1)^2 的根是 2,−1,−12,-1,-1，而框中公式给出 −2,1,1-2,1,1。正确的形式是

uk=2−p3cos⁡(13arccos⁡(3q2p−3p)−2kπ3),k=0,1,2.u_k=2\sqrt{-\frac p3}\cos\left(\frac13\arccos\left(\frac{3q}{2p}\sqrt{-\frac3p}\right)-\frac{2k\pi}{3}\right),\quad k=0,1,2 .

  1. 根的情况表中“pq=0pq=0：三重实根”应为“p=q=0p=q=0”。只有 pq=0pq=0 时不一定有三重根，例如 u3+1=0u^3+1=0（p=0p=0）只有一个实根。表中 Δ=0\Delta=0 且 pq=0pq=0 恰好等价于 p=q=0p=q=0。

不经过复数的推导（韦达三角代换）。 Δ<0\Delta<0 时 p<0p<0。令 u=mcos⁡φu=m\cos\varphi，取 m=2−p/3m=2\sqrt{-p/3}，使 pm=−34m3pm=-\frac34m^3，于是

为什么复数会消失？

关键在于 vw=−p/3vw = -p/3 是实数约束。vv 和 ww 互为共轭复数：

v=r1/3eiθ/3,w=vˉ=r1/3e−iθ/3v = r^{1/3}e^{i\theta/3}, \quad w = \bar{v} = r^{1/3}e^{-i\theta/3}

所以

u=−(v+w)=−2r1/3cos⁡θ3∈Ru = -(v+w) = -2r^{1/3}\cos\frac{\theta}{3} \in \mathbb{R}

另外两个根对应 θ\theta 替换为 θ+2π\theta + 2\pi、θ+4π\theta + 4\pi，同样是实数。复数只是计算的"中间语言"，最终虚部两两抵消。

历史意义

不可约情形在历史上证明了一件重要的事：即使方程的根全是实数，有时也无法避免在推导过程中经过复数。这正是推动复数被数学家认真对待的重要动力之一。
