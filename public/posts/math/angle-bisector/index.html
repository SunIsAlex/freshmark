补充：增根 nt=−8nt = -8 的几何意义与完善解析

1. 增根 nt=−8nt = -8 是什么？

上面方程解出的两个根分别为：

t1=n2  ⟹  Q1(0,n2),t2=−8n  ⟹  Q2(0,−8n)t_1 = \frac{n}{2} \implies Q_1\left(0, \frac{n}{2}\right), \qquad t_2 = -\frac{8}{n} \implies Q_2\left(0, -\frac{8}{n}\right)

计算焦点 F(2,0)F(2, 0) 与两交点连线的斜率：

kFQ1=n2−00−2=−n4,kFQ2=−8n−00−2=4nk_{FQ_1} = \frac{\frac{n}{2} - 0}{0 - 2} = -\frac{n}{4}, \qquad k_{FQ_2} = \frac{-\frac{8}{n} - 0}{0 - 2} = \frac{4}{n}

满足 kFQ1⋅kFQ2=−1k_{FQ_1} \cdot k_{FQ_2} = -1，即 FQ1⊥FQ2FQ_1 \perp FQ_2：

  • t=n2t = \frac{n}{2}（nt>0nt > 0）：Q1Q_1 与 PP 在 xx 轴同侧，FQ1FQ_1 是 ∠PFO\angle PFO 的内角平分线；
  • nt=−8nt = -8（nt<0nt < 0）：Q2Q_2 与 PP 在 xx 轴异侧，FQ2FQ_2 是 ∠PFO\angle PFO 的外角平分线（与内角平分线垂直）。

之所以在代数求解中产生外角平分线这个“增根”，有两个等价原因：

  1. 正切周期为 π\pi：将角平分线的角 α\alpha 换成与其垂直的外角平分线倾角 α′=α−π2\alpha' = \alpha - \frac{\pi}{2} 时，tan⁡(2α′)=tan⁡(2α−π)=tan⁡2α\tan(2\alpha') = \tan(2\alpha - \pi) = \tan 2\alpha，因此正切二倍角方程同时包含内外两条角平分线。
  2. f(x)=1x−x4f(x) = \frac{1}{x} - \frac{x}{4} 并非在 R∖{0}\mathbb{R}\setminus\{0\} 上单调：因 f′(x)=−1x2−14<0f'(x) = -\frac{1}{x^2} - \frac{1}{4} < 0，函数只在 (−∞,0)(-\infty, 0) 和 (0,+∞)(0, +\infty) 上各自严格单调递减，每个函数值都会被一正一负两个自变量（满足 xy=−4xy = -4）取到。

2. 完善解析（对称性 + 余切避免分类讨论）

  1. 利用对称性锁定同一单调区间：由抛物线 y2=8xy^2 = 8x 关于 xx 轴对称，不妨设 n>0n > 0（n<0n < 0 时同理可得相同的比值）。因为 FQFQ 是 ∠PFO\angle PFO 的内角平分线，点 Q(0,t)Q(0, t) 与 P(m,n)P(m, n) 必在 xx 轴同侧，故 t>0t > 0。
  2. 用 cot⁡2α\cot 2\alpha 统一包含 n=4n = 4（PF⊥xPF \perp x 轴）的情形：设 ∠QFO=α∈(0,π2)\angle QFO = \alpha \in \left(0, \frac{\pi}{2}\right)，则 tan⁡α=t2\tan\alpha = \frac{t}{2}，于是

cot⁡2α=1−tan⁡2α2tan⁡α=1t−t4.\cot 2\alpha = \frac{1 - \tan^2\alpha}{2\tan\alpha} = \frac{1}{t} - \frac{t}{4}.

另一方面，由 FO→=(−2,0)\overrightarrow{FO} = (-2, 0) 与 FP→=(n28−2,n)\overrightarrow{FP} = \left(\frac{n^2}{8} - 2, n\right)，对所有 n>0n > 0（包括 n=4n = 4 即 2α=π22\alpha = \frac{\pi}{2} 时 cot⁡2α=0\cot 2\alpha = 0）都有

cot⁡2α=2−n28n=2n−n8=1n2−n24.\cot 2\alpha = \frac{2 - \frac{n^2}{8}}{n} = \frac{2}{n} - \frac{n}{8} = \frac{1}{\frac{n}{2}} - \frac{\frac{n}{2}}{4}.

  1. 单调性直接定根：构造函数 f(x)=1x−x4f(x) = \frac{1}{x} - \frac{x}{4}。在 (0,+∞)(0, +\infty) 上 f′(x)=−1x2−14<0f'(x) = -\frac{1}{x^2} - \frac{1}{4} < 0，故 f(x)f(x) 在 (0,+∞)(0, +\infty) 上严格单调递减（一一对应）。结合 t>0t > 0、n2>0\frac{n}{2} > 0 与 f(t)=f(n2)f(t) = f\left(\frac{n}{2}\right)，唯一得

t=n2  ⟹  tn=12.t = \frac{n}{2} \implies \frac{t}{n} = \frac{1}{2}.

1. 为什么 MM 只能是 PP 在 l0l_0 上的垂足？
