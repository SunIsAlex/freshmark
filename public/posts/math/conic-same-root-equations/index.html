核心方法回顾：同解方程

1. 什么时候用？

两条二次曲线有两个公共点（最常见于圆锥曲线与圆的交线，例如三角形外接圆、过两定点与圆锥曲线两交点的圆等）。

2. 为什么能用？

同一条直线截两条二次曲线，截出完全相同的两个交点：

  • 直线与圆锥曲线联立，消元得到一元二次方程 ①；
  • 直线与圆联立，消去同一个元得到一元二次方程 ②；
  • 因为两方程在几何上具有相同的两实根，由韦达定理可知对应项系数成正比： a1a2=b1b2=c1c2\frac{a_1}{a_2} = \frac{b_1}{b_2} = \frac{c_1}{c_2}

3. 怎么用？（四步走）

  1. 设线：根据题意设直线方程（如 x=my+nx = my + n 或 y=kx+my = kx + m）；
  2. 和曲线联立：将直线代入圆锥曲线方程，整理得关于 yy（或 xx）的一元二次方程 ①；
  3. 设圆，和圆联立：设圆的一般方程 x2+y2+dx+ey+f=0x^2 + y^2 + dx + ey + f = 0，代入圆上已知定点消去参数，再将直线代入消去相同字母，得到方程 ②；
  4. 对应系数成比例：锁定设问目标（如外心坐标、斜率关系等），仅提取目标相关的系数比例式进行化简计算。

[!TIP] 同解方程方法的核心优势在于避开繁琐的设点韦达再代入外心垂直平分线的过程，将二元几何条件直接收敛为单一方程的系数比例关系。
