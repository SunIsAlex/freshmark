原题

（2024·顺义一模，19） 已知椭圆 E:x2a2+y2b2=1 (a>b>0)E:\dfrac{x^2}{a^2}+\dfrac{y^2}{b^2}=1\ (a>b>0) 的右焦点为 F(1,0)F(1,0)，长轴长为 222\sqrt{2}。过 FF 作斜率为 k1k_1 的直线交 EE 于 A,BA,B 两点，过点 FF 作斜率为 k2k_2 的直线交 EE 于 C,DC,D 两点，设 AB,CDAB,CD 的中点分别为 M,NM,N。

（1）求椭圆 EE 的方程；

（2）若 k1k2=−1k_1k_2=-1，设点 FF 到直线 MNMN 的距离为 dd，求 dd 的取值范围。

一、常规解法（标准应试思路）

（1）求椭圆 EE 的方程

由题意可知，右焦点为 F(1,0)F(1,0)，长轴长为 222\sqrt{2}，因此

c=1,2a=22  ⟹  a=2,c = 1, \qquad 2a = 2\sqrt{2} \implies a = \sqrt{2},

进而 b2=a2−c2=2−1=1b^2 = a^2 - c^2 = 2 - 1 = 1。故椭圆 EE 的标准方程为

x22+y2=1.\frac{x^2}{2} + y^2 = 1.

（2）求点 FF 到直线 MNMN 的距离 dd 的取值范围

由 k1k2=−1k_1k_2 = -1 可知 k1,k2k_1, k_2 均存在且不为 00，且 k2=−1k1k_2 = -\dfrac{1}{k_1}。

第一步：联立求中点 M,NM, N 的坐标

设直线 ABAB 的方程为 y=k1(x−1)y = k_1(x - 1)，与椭圆方程 x2+2y2=2x^2 + 2y^2 = 2 联立并消去 yy：

x2+2k12(x−1)2=2  ⟺  (2k12+1)x2−4k12x+2k12−2=0.x^2 + 2k_1^2(x - 1)^2 = 2 \iff (2k_1^2 + 1)x^2 - 4k_1^2 x + 2k_1^2 - 2 = 0.

因为点 F(1,0)F(1,0) 在椭圆 EE 内部，故判别式 Δ>0\Delta > 0 恒成立。设 A(x1,y1),B(x2,y2)A(x_1, y_1), B(x_2, y_2)，由韦达定理得

x1+x2=4k122k12+1.x_1 + x_2 = \frac{4k_1^2}{2k_1^2 + 1}.

因此弦 ABAB 的中点 MM 的坐标为

xM=x1+x22=2k122k12+1,yM=k1(xM−1)=−k12k12+1.x_M = \frac{x_1 + x_2}{2} = \frac{2k_1^2}{2k_1^2 + 1}, \qquad y_M = k_1(x_M - 1) = \frac{-k_1}{2k_1^2 + 1}.

同理，将 k1k_1 替换为 k2=−1k1k_2 = -\dfrac{1}{k_1}，直接可得弦 CDCD 的中点 NN 的坐标为

xN=2k222k22+1=2k12+2,yN=−k22k22+1=k1k12+2.x_N = \frac{2k_2^2}{2k_2^2 + 1} = \frac{2}{k_1^2 + 2}, \qquad y_N = \frac{-k_2}{2k_2^2 + 1} = \frac{k_1}{k_1^2 + 2}.

第二步：求直线 MNMN 的方程（注意分类讨论斜率是否存在）

  1. 当 xM=xNx_M = x_N 时： 2k122k12+1=2k12+2  ⟺  k14=1  ⟺  k1=±1.\frac{2k_1^2}{2k_1^2 + 1} = \frac{2}{k_1^2 + 2} \iff k_1^4 = 1 \iff k_1 = \pm 1.此时 xM=xN=23x_M = x_N = \dfrac{2}{3}，直线 MNMN 的方程为 x=23x = \dfrac{2}{3}，点 F(1,0)F(1,0) 到直线 MNMN 的距离为 d=∣1−23∣=13.d = \left|1 - \frac{2}{3}\right| = \frac{1}{3}.

  2. 当 xM≠xNx_M \neq x_N（即 k1≠±1k_1 \neq \pm 1）时： 直线 MNMN 的斜率为 kMN=yM−yNxM−xN=−k12k12+1−k1k12+22k122k12+1−2k12+2=−3k1(k12+1)2(k14−1)=−3k12(k12−1).k_{MN} = \frac{y_M - y_N}{x_M - x_N} = \frac{\dfrac{-k_1}{2k_1^2 + 1} - \dfrac{k_1}{k_1^2 + 2}}{\dfrac{2k_1^2}{2k_1^2 + 1} - \dfrac{2}{k_1^2 + 2}} = \frac{-3k_1(k_1^2 + 1)}{2(k_1^4 - 1)} = \frac{-3k_1}{2(k_1^2 - 1)}.于是直线 MNMN 的方程为 y−−k12k12+1=−3k12(k12−1)(x−2k122k12+1).y - \frac{-k_1}{2k_1^2 + 1} = \frac{-3k_1}{2(k_1^2 - 1)}\left(x - \frac{2k_1^2}{2k_1^2 + 1}\right).整理化简： y=−3k12(k12−1)x+3k13(k12−1)(2k12+1)−k12k12+1=−3k12(k12−1)(x−23),y = \frac{-3k_1}{2(k_1^2 - 1)}x + \frac{3k_1^3}{(k_1^2 - 1)(2k_1^2 + 1)} - \frac{k_1}{2k_1^2 + 1} = \frac{-3k_1}{2(k_1^2 - 1)}\left(x - \frac{2}{3}\right),即 3k1x+2(k12−1)y−2k1=0.3k_1 x + 2(k_1^2 - 1)y - 2k_1 = 0.不难检验，当 k1=±1k_1 = \pm 1 时该方程退化为 x=23x = \dfrac{2}{3}，因此对一切 k1≠0k_1 \neq 0，直线 MNMN 均统一表示为 3k1x+2(k12−1)y−2k1=03k_1 x + 2(k_1^2 - 1)y - 2k_1 = 0，且恒过定点 T(23,0)T\left(\dfrac{2}{3}, 0\right)。

第三步：求 dd 的表达式与取值范围

由点到直线的距离公式，点 F(1,0)F(1, 0) 到直线 MNMN 的距离为

d=∣3k1⋅1+0−2k1∣9k12+4(k12−1)2=∣k1∣4k14+k12+4=14k12+4k12+1.d = \frac{|3k_1 \cdot 1 + 0 - 2k_1|}{\sqrt{9k_1^2 + 4(k_1^2 - 1)^2}} = \frac{|k_1|}{\sqrt{4k_1^4 + k_1^2 + 4}} = \frac{1}{\sqrt{4k_1^2 + \dfrac{4}{k_1^2} + 1}}.

因为 k1≠0k_1 \neq 0，故 k12>0k_1^2 > 0。由基本不等式可得

4k12+4k12+1≥24k12⋅4k12+1=9,4k_1^2 + \frac{4}{k_1^2} + 1 \ge 2\sqrt{4k_1^2 \cdot \frac{4}{k_1^2}} + 1 = 9,

当且仅当 4k12=4k124k_1^2 = \dfrac{4}{k_1^2}，即 k1=±1k_1 = \pm 1 时等号成立；且当 k12→0+k_1^2 \to 0^+ 或 k12→+∞k_1^2 \to +\infty 时，4k12+4k12+1→+∞4k_1^2 + \dfrac{4}{k_1^2} + 1 \to +\infty，于是 d→0+d \to 0^+。

因此，

0<d≤13,0 < d \le \frac{1}{3},

即 dd 的取值范围是 (0,13]\left(0, \dfrac{1}{3}\right]。

易错细节提示：为什么是左开右闭 (0,13]\left(0, \dfrac{1}{3}\right]？

  • 左端点 00 取不到：题干给出 k1k2=−1k_1k_2 = -1，隐含两条直线斜率均存在且非零，即两条弦都不与坐标轴重合，因而 yM,yN≠0y_M, y_N \neq 0，直线 MNMN 永远不能退化为 xx 轴（过 FF），所以 d>0d > 0。
  • 右端点 13\dfrac{1}{3} 取得到：当 k1=±1k_1 = \pm 1 时，MNMN 为竖直线 x=23x = \dfrac{2}{3}，恰好垂直于线段 FTFT，此时 d=∣FT∣=13d = |FT| = \dfrac{1}{3}。

二、命题背景深度解读：为什么直线 MNMN 一定过定点？

在常规解法中，化简出 3k1x+2(k12−1)y−2k1=03k_1 x + 2(k_1^2 - 1)y - 2k_1 = 0 时，(2k12+1)(2k_1^2+1) 神奇地约掉了，直线 MNMN 莫名其妙地恒过定点 T(23,0)T\left(\dfrac{2}{3}, 0\right)。这绝非代数巧合，而是由两层非常经典的几何背景叠加而成的。

视角 1（核心背景）：弦中点轨迹“中点椭圆” + 弗雷吉耶（Frégier）直角弦定理

第一步：点差法揭示中点 M,NM, N 所在的“小椭圆”

对原椭圆 E:x22+y2=1E:\dfrac{x^2}{2} + y^2 = 1 上任意弦 ABAB（中点为 M(x,y)M(x, y)），由点差法知：

x12−x222+(y12−y22)=0  ⟹  x1+x22⋅x1−x22+(y1+y2)(y1−y2)=0,\frac{x_1^2 - x_2^2}{2} + (y_1^2 - y_2^2) = 0 \implies \frac{x_1 + x_2}{2}\cdot\frac{x_1 - x_2}{2} + (y_1 + y_2)(y_1 - y_2) = 0,

当弦不竖直时即 kOM⋅kAB=−b2a2=−12k_{OM} \cdot k_{AB} = -\dfrac{b^2}{a^2} = -\dfrac{1}{2}。

又因为弦 ABAB 过定点 F(1,0)F(1, 0)，当 M≠FM \neq F 时有 kAB=kFM=yx−1k_{AB} = k_{FM} = \dfrac{y}{x - 1}，代入立即得到

yx⋅yx−1=−12  ⟺  x(x−1)2+y2=0.\frac{y}{x} \cdot \frac{y}{x - 1} = -\frac{1}{2} \iff \frac{x(x - 1)}{2} + y^2 = 0.

配方化为标准形式：

E′:(x−12)214+y218=1.E': \frac{\left(x - \frac{1}{2}\right)^2}{\frac{1}{4}} + \frac{y^2}{\frac{1}{8}} = 1.

（检验易知，当弦为 xx 轴时中点 O(0,0)O(0,0)、当弦竖直时中点 F(1,0)F(1,0) 均满足此方程。）

这就是过定点弦的中点轨迹——中点椭圆 E′E'，它有三个极其优美的几何特征：

  1. 中心与长轴：中心为 O′(12,0)O'\left(\dfrac{1}{2}, 0\right)（OFOF 中点），以线段 OFOF 为长轴，O(0,0)O(0,0) 与 F(1,0)F(1,0) 分别是它的左、右顶点；
  2. 与原椭圆相似：半长轴 a′=12a' = \dfrac{1}{2}，半短轴 b′=24b' = \dfrac{\sqrt{2}}{4}，满足 b′a′=ba=22\dfrac{b'}{a'} = \dfrac{b}{a} = \dfrac{\sqrt{2}}{2}，即 E′E' 是原椭圆 EE 缩小为 c2a=e2\dfrac{c}{2a} = \dfrac{e}{2} 倍后的位似图形；
  3. 关键转化：因为 M∈ABM \in AB、N∈CDN \in CD 且 AB⊥CDAB \perp CD，所以原题瞬间转化为——

    在“中点椭圆” E′E' 上，从右顶点 FF 引出两条互相垂直的弦 FM⊥FNFM \perp FN，求弦 MNMN 的性质！

第二步：直接对接“弗雷吉耶（Frégier）定理”

高考解析几何中有一个妇孺皆知的经典母题——弗雷吉耶定理（椭圆直角弦定点定理）：

过椭圆 X2a′2+Y2b′2=1\dfrac{X^2}{a'^2} + \dfrac{Y^2}{b'^2} = 1 上任意一定点 PP 作两条互相垂直的弦 PM⊥PNPM \perp PN，则直线 MNMN 恒过该椭圆在 PP 点法线上的一个定点（称为 PP 的弗雷吉耶点）。特别地，当 PP 为右顶点 (a′,0)(a', 0) 时，该定点为 T(a′⋅a′2−b′2a′2+b′2, 0).T\left(a'\cdot\frac{a'^2 - b'^2}{a'^2 + b'^2},\ 0\right).

把中点椭圆 E′E' 的参数（中心在 x=c2x = \dfrac{c}{2}，a′=c2a' = \dfrac{c}{2}，b′a′=ba\dfrac{b'}{a'} = \dfrac{b}{a}）直接代回：

xT=c2+c2⋅a′2−b′2a′2+b′2=c2(1+a2−b2a2+b2)=a2ca2+b2.x_T = \frac{c}{2} + \frac{c}{2} \cdot \frac{a'^2 - b'^2}{a'^2 + b'^2} = \frac{c}{2}\left(1 + \frac{a^2 - b^2}{a^2 + b^2}\right) = \frac{a^2 c}{a^2 + b^2}.

代入本题 a2=2,b2=1,c=1a^2 = 2, b^2 = 1, c = 1，立得

xT=2×12+1=23  ⟹  T(23,0).x_T = \frac{2 \times 1}{2 + 1} = \frac{2}{3} \implies T\left(\frac{2}{3}, 0\right).

这就是本题最核心的命题真相：命题人把“椭圆顶点直角弦过定点”藏在了“大椭圆焦点弦的中点椭圆”里，相当于在经典模型外面套了一层“弦中点轨迹”的外壳！

视角 2（直觉本质）：仿射变换“伸缩变圆”——为什么定点偏向 FF 而不是中心 O′O'？

如果读者进一步追问：为什么圆里“顶点直角弦过圆心”，而椭圆里定点会从中心 O′(12,0)O'\left(\dfrac{1}{2}, 0\right) 偏移到 T(23,0)T\left(\dfrac{2}{3}, 0\right)？ 做一次纵向仿射伸缩即可豁然开朗。

令 X=x, Y=2 yX = x,\ Y = \sqrt{2}\,y，将整个平面沿 yy 轴拉伸 2\sqrt{2} 倍：

  1. 原椭圆变圆：E:x22+y2=1E: \dfrac{x^2}{2} + y^2 = 1 变为圆 C:X2+Y2=2C: X^2 + Y^2 = 2，焦点 F(1,0)F(1, 0) 变为定点 F′(1,0)F'(1, 0)。
  2. 中点轨迹瞬间显现：在圆 CC 中，由垂径定理知弦 A′B′A'B' 的中点 M′M' 必满足 OM′⊥A′B′OM' \perp A'B'，即 ∠OM′F′=90∘\angle OM'F' = 90^\circ！无需任何点差法计算，立得 M′M' 的轨迹是以 OF′OF' 为直径的圆： C′:X(X−1)+Y2=0.C': X(X - 1) + Y^2 = 0.再把圆 C′C' 沿纵轴压回 12\dfrac{1}{\sqrt{2}} 倍，自然就是中点椭圆 E′E'！
  3. 垂直条件变为“圆上斜率积定值（对合）”： 伸缩变换将斜率都乘以 2\sqrt{2}，因此 k1k2=−1k_1k_2 = -1 变成圆 C′C' 上的 K1K2=(2k1)(2k2)=−a2b2=−2.K_1 K_2 = (\sqrt{2}k_1)(\sqrt{2}k_2) = -\frac{a^2}{b^2} = -2.
    • 若圆上满足 K1K2=−1K_1 K_2 = -1（真正的直角 ∠M′F′N0=90∘\angle M'F'N_0 = 90^\circ），由泰勒斯定理，M′N0M'N_0 是直径，恒过圆心 O′(12,0)O'\left(\dfrac{1}{2}, 0\right)；
    • 如今斜率积被“拉陡”为 K1K2=−2K_1 K_2 = -2，这在射影几何中仍是圆上的一组对合（Involution），对应点连线依然恒过直径 OF′OF' 上的定点，只是由于 ∣K1K2∣=2>1|K_1 K_2| = 2 > 1，定点被从圆心 O′(12,0)O'\left(\dfrac{1}{2}, 0\right) 拉向了 F′(1,0)F'(1, 0)，恰好落在 T′(23,0)T'\left(\dfrac{2}{3}, 0\right)（在 M′F′M'F' 斜率固定时，K2=−2/K1K_2 = -2/K_1 比 −1/K1-1/K_1 更陡，把另一端点 N′N' 推向了更靠近 F′F' 的一侧）。
  4. 由于仿射变换保持共线与 xx 轴坐标不变，压缩回原椭圆后，直线 MNMN 恒过定点 T(23,0)T\left(\dfrac{2}{3}, 0\right)。

视角 3：为什么题目问“距离 dd 的范围”，而不直接问“定点”？

如果直接问“证明直线 MNMN 过定点”，套路过于直白。命题人将“过定点 T(23,0)T\left(\dfrac{2}{3}, 0\right)”藏在了距离 dd 的背后：

  • 对过定点 TT 的任意动直线 ll，定点 FF 到 ll 的距离满足几何不等式 d=∣FT∣sin⁡θ≤∣FT∣=13,d = |FT|\sin\theta \le |FT| = \frac{1}{3},其中 θ∈(0,π)\theta \in (0, \pi) 为直线 ll 与 FTFT 的夹角（即倾斜角）。
  • 一方面，这让看不出定点的同学不得不通过复杂的分式化简 + 基本不等式硬算；另一方面，看透定点的同学不仅能瞬间预判最大值就是 ∣FT∣=13|FT| = \dfrac{1}{3}，还能反过来校验自己的代数运算是否出错。

三、更简便的解法与一般化推广

更简便解法：点差法得中点椭圆 + 平移齐次化（全程无坐标、无分类）

把上面的背景直接落成解题过程，可以得到极其干净、完全不需要算 M,NM, N 坐标、不需要算 kMNk_{MN}、也不需要分类讨论斜率是否存在的解法：

第一步（点差法求中点轨迹）：

设过 F(1,0)F(1, 0) 且斜率为 kk（k≠0k \neq 0）的弦的中点为 (x,y)(x, y)。由点差法有 x2+y⋅k=0\dfrac{x}{2} + y \cdot k = 0，又 k=yx−1k = \dfrac{y}{x - 1}，消去 kk 得

x(x−1)+2y2=0.x(x - 1) + 2y^2 = 0.

故 M,NM, N 均在椭圆 E′:x2−x+2y2=0E': x^2 - x + 2y^2 = 0 上，且 F(1,0)F(1,0) 也在 E′E' 上。

第二步（平移至 FF 后齐次化，3 行锁定直线 MNMN）：

令 u=x−1, v=yu = x - 1,\ v = y（将坐标原点平移至右焦点 FF），则 E′E' 的方程化为

u2+u+2v2=0.u^2 + u + 2v^2 = 0.

因为 k1,k2k_1, k_2 存在且非零、k1≠k2k_1 \neq k_2，所以 M,N,FM, N, F 是椭圆 E′E' 上互不重合的三个点；由直线与椭圆至多有两个交点可知，直线 MNMN 必不过新原点 F(0,0)F(0, 0)。从而直线 MNMN 总可唯一设为（包含竖直线 q=0q = 0 的情形！）

pu+qv=1.pu + qv = 1.

将其代入 E′E' 的方程进行齐次化：

u2+2v2+u(pu+qv)=0  ⟺  2v2+q uv+(1+p)u2=0.u^2 + 2v^2 + u(pu + qv) = 0 \iff 2v^2 + q\,uv + (1 + p)u^2 = 0.

因 M,NM, N 的横坐标均不等于 11（即 u≠0u \neq 0），两边同除以 u2u^2，得关于斜率 k=vuk = \dfrac{v}{u} 的一元二次方程：

2k2+qk+(1+p)=0,2k^2 + qk + (1 + p) = 0,
