21.（本小题15分）

对于任意数列 \(c_1, c_2, \dots, c_m\)，从中选取第 \(i_1\) 项、第 \(i_2\) 项、\(\dots\)、第 \(i_k\) 项（\(i_1 < i_2 < \dots < i_k\)，\(1 \le k \le m\)），称新数列 \(c_{i_1}, c_{i_2}, \dots, c_{i_k}\) 为数列 \(c_1, c_2, \dots, c_m\) 的一个长度为 \(k\) 的子列。记 \(P(c_1, \dots, c_m) = \{c_{i_1} + c_{i_2} + \dots + c_{i_k} \mid 1 \le i_1 < i_2 < \dots < i_k \le m, 1 \le k \le m\}\) 为其全部子列之和所组成的集合，记 \(|P(c_1, \dots, c_m)|\) 为集合 \(P(c_1, \dots, c_m)\) 中元素的个数。

（I）对于数列 \(A_1: 1, 2, 2\) 与 \(A_2: -1, -1, 2\)，直接写出集合 \(P(1, 2, 2)\) 与 \(P(-1, -1, 2)\)；

（II）若 \(n \ge 2\)，正项数列 \(a_1, a_2, \dots, a_n\) 满足：\(\forall k \in \{1, 2, \dots, n-1\}\)，都有 \(a_{k+1} > a_1 + a_2 + \dots + a_k\)，求 \(|P(a_1, a_2, \dots, a_n)|\) 的值；

（III）若 \(n \ge 4\)，数列 \(a_1, a_2, \dots, a_n\) 各项都是整数，且正项与负项的个数都不小于 \(2\)。如果 \(0 \notin P(a_1, a_2, \dots, a_n)\)，求$|P(a_1,a_2,\cdots,a_n)|$的最小值.

(I)
$P(1,2,2)=\{1,2,3,4,5\},P(-1,-1,2)=\{-1,2,-2,1,0\}$
(II)
第一想法，这道题与**二进制**有关，因为数列:
$$1,2,4,8,16,...$$
恰好符合\(\forall k \in \{1, 2, \dots, n-1\}\)，都有 \(a_{k+1} > a_1 + a_2 + \dots + a_k\).
那么，我们可以猜测:
$$|P(a_1, a_2, \dots, a_n)|=2^n-1$$
每一项都有“在子列中”和“不在子列中”两种可能，且不能所有项都不在子列中（否则子列为空集），我们恰要说明不同的选取可能与不同的子列和一一对应。
容易知道存在单增序列:
$$a_1\lt a_2\lt a_1+a_2\lt a_3\lt a_3+a_1\lt a_3+a_2\lt a_3+a_2+a_1\lt a_4\lt\cdots$$
这完美地与二进制的数码一一对应，问题在于如何书写。
或许，第一数学归纳法是一个好主意，因为$n$较小时的情况，可以用枚举法说明。
当$n=2$时，我们有:
$$a_1\lt a_2\lt a_1+a_2$$
即$|P(a_1,a_2)|=3$.
设当$n=k$时，$|P(a_1,a_2,\cdots,a_k)|=2^k-1$,则:
对于$P(a_1,a_2,\cdots,a_k,a_{k+1})$中的子列和，可以分成以下三类：
- 仅含有$a_1,a_2,\cdots,a_k$中的项($2^{k}-1$个)
- 仅含有$a_{k+1}$($1$个)
- 既含有$a_{k+1}$,也含有$a_1,a_2,\cdots,a_k$中的项($2^k-1$个)

由归纳假设，第一类的$2^k-1$个和互不相同；第三类的和恰为第一类的每个和加上$a_{k+1}$，所以也互不相同。
再看类间：设$S$是第一类中的任意一个和，由$a_i\gt 0$得:
$$S\le a_1+a_2+\cdots+a_k\lt a_{k+1}\lt a_{k+1}+S$$
即第一类的和都小于第二类的和，第二类的和都小于第三类的和，三类之间不可能重复。
因此，可以证明:
$$|P(a_1,a_2,\cdots,a_{k},a_{k+1})|=(2^k-1)+1+(2^k-1)=2^{k+1}-1$$
综上，归纳证明完毕.

**另解（II）** 任取两个不同子列，分别记为 \(B\)、\(C\)。考虑这两个子列不同的项（即恰在一个子列中出现的项），设其**下标的最大值为 \(j\)**，则 \(j \ge 1\)，不妨设 \(a_j\) 为 \(B\) 中的项。

若 \(j=1\)，则 \(B\) 中所有项之和减去 \(C\) 中所有项之和为 \(a_1 > 0\)。

若 \(j \ge 2\)，则 \(B\) 中所有项之和减去 \(C\) 中所有项之和 \(\ge a_j - (a_1 + a_2 + \dots + a_{j-1}) > 0\)，

从而任意两个不同子列的和都不相等，因此 \(|P(a_1, a_2, \dots, a_n)| = 2^n - 1\)。

(III)
显然，由于\(0 \notin P(a_1, a_2, \dots, a_n)\),必然有$a_i\ne0(i=1,2,\cdots,n)$.
不妨对数列进行排序，这不影响条件和结论:
$$a_1\le a_2\le \cdots\le a_s\lt 0\lt a_{s+1}\le a_{s+2}\le \cdots \le a_{s+t},\\
s+t=n,s\ge2,t\ge2$$
我们先研究一个简化的情况:
$$a_i\in \N^*\\
a_1\le a_2\le \cdots\le a_n$$
仿照(II)，使用数学归纳法:
当$n=2,0\lt a_1\le a_2$,显然有$|P(a_1,a_2)|\ge 2$.
设当$n=k$时，$|P(a_1,a_2,\cdots,a_k)|\ge k$，则:
必然有$|P(a_1,a_2,\cdots,a_k,a_{k+1})|\ge k+1$,因为$a_1+a_2+\cdots a_{k+1}\notin P(a_1,a_2,\cdots,a_k)$.
取等条件容易构造:$a_1=a_2=\cdots=a_k=a_{k+1}$.
那么，类似有:
$$|P(a_1,a_2,\cdots,a_s)|\ge s\\
|P(a_{s+1},a_{s+2},\cdots,a_{s+t})|\ge t$$
自此，证明卡住了，因为不清楚交叉项会不会对$|P(a_1,a_2,\cdots,a_n)|$有贡献.

---

 我们更换思路，考虑:
 $$a_1,a_2,\cdots,a_s\lt 0\\
 a_{s+1},a_{s+2},\cdots,a_{s+t}\gt 0\\
 s+t=n,s\ge2,t\ge2$$
 定义:
 $$x_i=-a_i\gt0(i=1,2,\cdots,s)\\
 y_i=a_{s+i}\gt0(i=1,2,\cdots,t)$$
 前缀和:
 $$X_k=\sum_{i=1}^{k} x_i,\ Y_k=\sum_{i=1}^{k} y_i,\ X_0=Y_0=0$$
 显然，$X_k,Y_k$都关于$k$严格单调递增.
 这样，我们可以统一地表述“交叉项的和”和“符号相同项的和”:
 $$F(u,v)=Y_v-X_u=(a_1+\cdots+a_u)+(a_{s+1}+\cdots+a_{s+v})\quad(0\le u\le s,0\le v\le t)$$
 当$u,v$不同时为$0$时，$F(u,v)$是一个子列和，即$F(u,v)\in P(a_1,a_2,\cdots,a_n)$.
 我们探索一下，$F(u,v)$会不会出现重复:
 假设$(u,v)\ne(u',v')$，但$F(u,v)=F(u',v')$，即:
 $$X_u-X_{u'}=Y_v-Y_{v'}$$
 如果$u=u'$，则$Y_v=Y_{v'}$，由$Y_k$的单调性，必然有$v=v'$，矛盾.
 不妨设$u\gt u'$，则左边$\gt0$，故$v\gt v'$，于是:
 $$x_{u'+1}+x_{u'+2}+\cdots+x_u=y_{v'+1}+y_{v'+2}+\cdots+y_v\\
 a_{u'+1}+a_{u'+2}+\cdots+a_u+a_{s+v'+1}+a_{s+v'+2}+\cdots+a_{s+v}=0$$
 左边是一个非空子列的和，这与\(0 \notin P(a_1, a_2, \dots, a_n)\)矛盾。
 所以，$F(u,v)$不会出现重复项.
 因此，我们有:
 $$\{F(u,v)\mid 0\le u\le s,0\le v\le t,u,v\text{不同时为0}\}\subseteq P(a_1,a_2,\cdots,a_n)\\
 |P(a_1,a_2,\cdots,a_n)|\ge(s+1)(t+1)-1=st+(s+t)=st+n$$
 注意这里只有$\ge$：$P$中可能还有不在上述集合中的子列和。
 又因为$s\ge2,t\ge2$:
 $$(s-2)(t-2)=st-2(s+t)+4\\
 =st-2n+4\ge0\\
 st\ge 2n-4$$
 综上，$|P(a_1,a_2,\cdots,a_n)|\ge 3n-4$.
 构造取等，只需要$\min\{s,t\}=2$，且其余子列和都落在上述集合中。取:
 $$1,1,\underbrace{-2n,-2n,\cdots,-2n}_{n-2\text{个}}$$
 此时正项子列和为$1,2$，负项子列和为$-2nk$，交叉子列和为$-2nk+1,-2nk+2$（$1\le k\le n-2$）。
 由于$n\ge4$，这些数都不为$0$，即\(0 \notin P\)，且两两不同，所以:
 $$|P|=2+(n-2)+2(n-2)=3n-4$$
 所以，$|P(a_1,a_2,\cdots,a_n)|$的最小值为$3n-4$.

---

**总结**

要说明两个子列和不相等，关键是**消去公共项，只比较不同的项**：
$$\sum B=\sum C\iff\sum(B\setminus C)=\sum(C\setminus B)$$

- 在（II）中，不同项里下标最大的那一项$a_j$，比其余所有可能出现的项之和还大，所以两边不可能相等。
- 在（III）中，题目条件\(0 \notin P\)只约束**单个**子列的和。因此要选一族子列（前缀和$F(u,v)$），使得任意两个子列的不同项移项后，恰好构成一个非空子列，并且它的和为$0$，这样才能用上条件导出矛盾。

直接按“纯正和、纯负和、交叉和”分类去比较之所以卡住，正是因为不同类的子列，其不同项移项后会带上减号，不再是一个子列的和，条件也就用不上了。
