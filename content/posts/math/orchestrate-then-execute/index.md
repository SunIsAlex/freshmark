在平面直角坐标系 $xOy$ 中，椭圆 $C$：$\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$ ($a > b > 0$) 的离心率为 $\frac{\sqrt{3}}{2}$，直线 $y = x$ 被椭圆 $C$ 截得的线段长为 $\frac{4\sqrt{10}}{5}$。

（1）求椭圆 $C$ 的方程；

（2）过原点的直线与椭圆 $C$ 交于 $A, B$ 两点（$A, B$ 不是椭圆 $C$ 的顶点），点 $D$ 在椭圆 $C$ 上，且 $AD \perp AB$，直线 $BD$ 与 $x$ 轴、$y$ 轴分别交于 $M, N$ 两点。

① 设直线 $BD, AM$ 的斜率分别为 $k_1, k_2$，证明存在常数 $\lambda$ 使得 $k_1 = \lambda k_2$，并求出 $\lambda$ 的值；

② 求 $\triangle OMN$ 面积的最大值。

（1）$\frac{x^2}{4}+\frac{y^2}{1}=1$

（2）条件复杂，且涉及到多步问题的求解。我们必须条分缕析，细致的分析解题路径。
(i)
# Orchestrator
## 路径1
设MN->$M(m,0),N(0,n),D(x_2,y_2),B(x_1,y_1)$->$A(-x_1,-y_1)$->$\frac{y_2+y_1}{x_2+x_1}\cdot\frac{y_1}{x_1}=-1$

想到这一步，便可以发现此路径的疑点：产生了不对称，有碍于问题求解.
## 路径2
设$A(x_1,y_1),B(-x_1,-y_1)$->$AD$->$D(x_2,y_2),x_1x_2,x_1+x_2$->$k_{BD}=\frac{y_2+y_1}{x_2+x_1}$->$M,N$

整体看来，路径2不涉及不对称式，优于路径1
# Executor
设$A(x_1,y_1),B(-x_1,-y_1),D(x_2,y_2),M(m,0),N(0,n),k_{AB}=\frac{y_1}{x_1}$,则:
$$AD:y=kx+b,k=-\frac{x_1}{y_1}\\
x^2+4y^2-4=0\\
x^2+4(kx+b)^2-4=0\\
(4k^2+1)x^2+8kbx+4(b^2-1)=0\\
k_1=k_{BD}=\frac{y_1+y_2}{x_1+x_2}\\
=\frac{k(x_1+x_2)+2b}{x_1+x_2}\\
=k+\frac{2b}{x_1+x_2}\\
=k+\frac{2b(4k^2+1)}{-8kb}=-\frac{1}{4k}\\
=\frac{y_1}{4x_1}$$
结果极度清爽，符合我们的预期:
$$BD:y=\frac{y_1}{4x_1}(x+x_1)-y_1\\
\text{let }y=0\Longrightarrow m=3x_1\\
k_2=k_{AM}=\frac{y_1}{x_1-3x_1}=-\frac{y_1}{2x_1}\\
\therefore k_1=-\frac{1}{2}k_2(y_1\ne 0)\\
\lambda=-\frac{1}{2}$$
(ii)
$$BD:y=\frac{y_1}{4x_1}(x+x_1)-y_1\\
\text{let }x=0\Longrightarrow n=-\frac{3}{4}y_1\\
S_{\triangle OMN}=\frac{1}{2}|m||n|\\
=\frac{9}{8}|x_1y_1|\\
x_1^2+4y_1^2=4\ge 4|x_1y_1|\\
|x_1y_1|\le1\\
S_{\triangle OMN}\le \frac{9}{8}$$

# 补充：路径1的硬解

虽然在 Orchestrator 阶段我们因为“不对称”而剪掉了路径 1，但实际上沿着路径 1 也能解出——关键在于**不要去求 $x_1$ 的具体值**，而是利用 $y_1 = k_1(x_1 - m)$ 把不对称项线性化，直接消出 $m$ 与 $x_1$ 的关系。

(i) 由题意，$A, B$ 不是椭圆顶点且 $AD \perp AB$，故直线 $BD$ 斜率 $k_1 \neq 0$ 且不过原点（$m \neq 0, n \neq 0$）。设 $BD: y = k_1(x - m)$（其中 $k_1 = -\frac{n}{m}$），联立 $x^2 + 4y^2 = 4$：
$$(1 + 4k_1^2)x^2 - 8k_1^2 m x + 4k_1^2 m^2 - 4 = 0$$
由韦达定理：
$$x_1 + x_2 = \frac{8k_1^2 m}{1 + 4k_1^2}\\
y_1 + y_2 = k_1(x_1 + x_2 - 2m) = -\frac{2k_1 m}{1 + 4k_1^2}$$
因为 $AD \perp AB$，即 $x_1(x_1 + x_2) + y_1(y_1 + y_2) = 0$，代入 $y_1 = k_1(x_1 - m)$ 与上述两式：
$$x_1 \cdot \frac{8k_1^2 m}{1 + 4k_1^2} + k_1(x_1 - m)\left(-\frac{2k_1 m}{1 + 4k_1^2}\right) = 0$$
两边同乘 $\frac{1 + 4k_1^2}{2k_1^2 m}$：
$$4x_1 - (x_1 - m) = 0 \Longrightarrow m = -3x_1$$
由于 $B(x_1, y_1)$ 和 $M(-3x_1, 0)$ 均在直线 $BD$ 上，而 $A(-x_1, -y_1)$：
$$k_1 = k_{BM} = \frac{y_1 - 0}{x_1 - (-3x_1)} = \frac{y_1}{4x_1}\\
k_2 = k_{AM} = \frac{0 - (-y_1)}{-3x_1 - (-x_1)} = -\frac{y_1}{2x_1}$$
故 $k_1 = -\frac{1}{2}k_2$，即 $\lambda = -\frac{1}{2}$。

(ii) 由 $N(0, n)$ 在 $BD: y = k_1(x - m)$ 上，得：
$$n = -k_1 m = -\frac{y_1}{4x_1} \cdot (-3x_1) = \frac{3}{4}y_1$$
故 $S_{\triangle OMN} = \frac{1}{2}|m||n| = \frac{9}{8}|x_1 y_1| \le \frac{9}{8}$（当且仅当 $x_1^2 = 2, y_1^2 = \frac{1}{2}$ 时取等号）。

路径 1 之所以能走通，是因为在“不对称式”里只代换了 $x_1 + x_2$ 与 $y_1 + y_2$，保住了 $x_1$ 的一次结构。但相比路径 2 全程无需顾忌“只消一半”的技巧，路径 1 在 Orchestrate 阶段确实更难一眼看穿。

# 总结

面对复杂的解析几何问题，**Execution（执行）** 拼的是基本功，而 **Orchestrate（编排）** 决定的则是整道题的计算下限。

很多时候“算不下去”，并不是算力不够，而是没有在动笔前先做一次低成本的路径推演：选对主元与切入点（保留对称性），繁琐的联立与消元就会顺理成章地收敛；方向一旦偏了，执行越努力，陷入的泥潭就越深。**先看清全局骨架，再动手展开细节——无论对人还是对 AI，这都是解决复杂问题最划算的策略。**
